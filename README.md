# Custom CSS for Twitter

Custom CSS to personalize the look and feel of Twitter (X).

## Installation

1. **Install Control Panel for Twitter**

   Download and install the [Control Panel for Twitter](https://github.com/insin/control-panel-for-twitter) browser extension.

2. **Copy the CSS code**

   Copy the CSS code from this repository that you want to use.

3. **Open the extension settings**

   Open the Control Panel for Twitter settings and scroll down to the **Custom CSS** section.

4. **Paste the CSS**

   Paste the copied CSS code into the **Custom CSS** text box.

5. **Save and enjoy!**

   Save your changes if required, then refresh Twitter (X) to see the changes.

## Requirements

* [Control Panel for Twitter](https://github.com/insin/control-panel-for-twitter)
* Twitter (X)
